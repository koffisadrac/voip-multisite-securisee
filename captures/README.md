# Captures

Les captures de mes tests sont intégrées au rapport (`docs/Rapport_VoIP_Kanga.pdf`), une figure par test.
Vous pouvez aussi les déposer ici séparément, nommées par test : `A06_show_ephone.png`, `B16_wireshark_chiffre.png`, `C04_flux_rtp.png`, etc.

Avant de publier une capture, masquer les mots de passe, NIP, clés VPN et lignes `a=crypto ... inline:` (clés SRTP).
